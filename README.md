# Dev Mindset - Gerador de Inspiração Diária

> Uma aplicação minimalista desenvolvida para trazer motivação e reflexões sobre código limpo e arquitetura de software.

![Status do Projeto](https://img.shields.io/badge/status-concluído-success)
![Tecnologias](https://img.shields.io/badge/stack-HTML5%20%7C%20TailwindCSS%20%7C%20JS-blue)

## Sobre o Projeto
Projeto desenvolvido com foco em **Clean Code**, **UI/UX minimalista** e alta performance, utilizando apenas tecnologias nativas da web integradas com Tailwind CSS.

## Tecnologias Utilizadas
- **HTML5** (Semântico)
- **Tailwind CSS** (Estilização moderna e responsiva)
- **JavaScript Vanilla (ES6+)** (Lógica e manipulação de estado)
